## 💡 Tips & Tricks

### Speed Up Development
1. Use Swagger UI for API testing (no need for Postman)
2. React dev server has hot-reload (auto-refresh on save)
3. SQL Server LocalDB doesn't require installation (built-in)
4. Use browser DevTools for frontend debugging (F12)

### Common Mistakes to Avoid
1. ❌ Starting both servers on the same port → Use 5050 and 3000
2. ❌ Forgetting to apply migrations → Run `dotnet ef database update`
3. ❌ Modifying app while it's running → Stop, modify, restart
4. ❌ Using wrong connection string → Check appsettings.json
5. ❌ Forgetting to install npm packages → Run `npm install`

### Performance Tips
1. ✅ Enable lazy loading in EF Core
2. ✅ Use pagination for large datasets
3. ✅ Cache frequently accessed data
4. ✅ Use indexes on foreign keys
5. ✅ Profile before optimizing
