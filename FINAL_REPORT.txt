═══════════════════════════════════════════════════════════════════════════════
						  🆘 TROUBLESHOOTING GUIDE 🆘
═══════════════════════════════════════════════════════════════════════════════

❌ Issue: Admin account not created
✅ Solution:
   1. Check API console logs
   2. Run: Update-Database (Package Manager Console)
   3. Delete database and restart app
   4. Manually call POST /api/auth/create-admin

❌ Issue: Login returns 401 Unauthorized
✅ Solution:
   1. Verify email is: admin@savmanager.com
   2. Verify password is: Admin@123456
   3. Check IsActive = true in database
   4. Verify Admin role exists in AspNetRoles table

❌ Issue: Bearer token not working
✅ Solution:
   1. Copy exact token without "Bearer " prefix
   2. Paste in Authorize field with "Bearer " prefix
   3. Or set Authorization header: Bearer {token}
   4. Check token hasn't expired (60 min expiration)

❌ Issue: CORS errors
✅ Solution:
   1. Ensure CORS policy configured in Program.cs
   2. Check your client origin matches allowed origins
   3. Verify credentials being sent if needed
