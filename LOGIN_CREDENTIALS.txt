## 🚀 Quick Start (3 Steps)

### Step 1️⃣ - Start the API
```bash
cd SAV.API
dotnet run
```

Wait until you see: ✅ **Default admin account created successfully.**

### Step 2️⃣ - Open Swagger
Go to: **https://localhost:5001/swagger**

### Step 3️⃣ - Login
1. Find **POST /api/auth/login**
2. Click **"Try it out"**
3. Paste this:
```json
{
  "email": "admin@savmanager.com",
  "password": "Admin@123456"
}
```
4. Click **Execute**
5. Copy the `accessToken` from response
6. Click **Authorize** (top-right) and paste: `Bearer {token}`
7. Done! ✅
